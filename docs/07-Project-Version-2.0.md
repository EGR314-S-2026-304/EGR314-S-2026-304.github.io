## Improvements
The current system could use some improvements, such as:
* A working motor system would allow for a scope to be adjusted with great precision, allowing the user to have more agency in how they study celestial objects.
* More commands for the motor system would enhance the accuracy and precision of the scope
* 

## Additions
Additions would be essential in a hypothetical version 2.0 of this project. Some additions would be:
* **A magnifying scope** would allow the user to actually view celestial objects.
* **A camera subsystem** or **IR sensor system**, alongside the aforementioned magnifying scope, would allow for the automatic taking of pictures through the magnified lenses of the scope. It would allow for the user to actually measure and study celestial objects.
* A shell to hold the whole system would improve the overall aesthetics of the system, make it more maneuverable, and improve the durability of the subsystems inside.
